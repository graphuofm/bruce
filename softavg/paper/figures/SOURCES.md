# Figure sources (repo only, not in the Overleaf zip)

Every PDF here is a copy of a figure generated from measured `results.json` (no hardcoded numbers).
Regenerate it in its experiment directory, then copy it again under the name below.

| file | generated by | what it shows |
|---|---|---|
| eps_crossover_native_alternatives.pdf | figures/eps_crossover_native_alternatives.py (reads experiments/crossover/results.json) | single-column 2x2: fraction of acceptable queries and median worst-group error vs eps for AVG, top-10k + softmax, best truncated AVG (IMDb, Amazon) |
| esci_true_vs_false_findings.pdf | figures/esci_true_vs_false_findings.py (reads experiments/esci_task/results.json; the relative-threshold family is not drawn) | true vs false findings on ESCI test, softavg / threshold / global top-k / per-group top-b |
| bound_slack_ratio_by_eps.pdf | experiments/bound/report.py | true error / InvAcc bound (median, p99, max) vs eps |
| bound_slack_vs_ops_since_refold.pdf | experiments/bound/report.py | slack ratio vs operations since the last fresh fold |
| bound_tolerance_refold_tradeoff.pdf | experiments/bound/report.py | refolded rows vs max error, ABS_TOL sweep and double-double state |
| ess_per_group_vs_eps.pdf | experiments/bound/report.py | effective sample size per group vs eps |
| host_contracts_execution.pdf | figures/host_contracts_execution.py (schematic, matplotlib; draw.io not installed) | one window frame slide in PostgreSQL / SQLite / DuckDB through the shared core |
| ladder_rolling_trace.pdf | figures/ladder_rolling_trace.py (reads experiments/softmax_ladder/trace.json) | Case 2: rolling softavg on Amazon in time order, SQLite engine runs: S1 / S3 / S4 error vs exact |
| window_cost_vs_k.pdf | figures/window_cost_vs_k.py (reads experiments/softmax_ladder/pg_window.jsonl, sqlite_timing.jsonl) | Case 2 window cost per rung vs frame size k, PostgreSQL 18.6 and SQLite (Amazon, eps = 0.02, smoke timings) |
| case3_fanout_latency.pdf | figures/case3_fanout_latency.py (reads experiments/multilabel/results_maint_join.json) | Case 3: per-delete latency vs fan-out, join view vs pg_ivm vs single-label view |

Fonts (2026-11-09): every figure uses a serif font (Nimbus Roman). The paper-side scripts set it themselves; the four bound figures were regenerated by experiments/bound/report.py with MATPLOTLIBRC pointing to a matplotlibrc containing `font.family: serif`, `font.serif: Nimbus Roman`, `mathtext.fontset: stix`, `pdf.fonttype: 42`.
